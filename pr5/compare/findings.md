# Висновок

У ході практичної роботи №5 було розроблено застосунок для семантичного пошуку та пошуку за ключовими словами BM25 у базі знань магазину «Сузір’я».

Для створення ембедінгів використано локальну модель intfloat/multilingual-e5-small. Проіндексовано 16 документів та проведено тестування на 12 запитах.

При розмірі фрагмента 600 символів семантичний пошук показав hit@1 — 63,6% та hit@3 — 81,8%. Для BM25 ці показники становили 54,5% та 63,6% відповідно.

Збільшення розміру фрагмента до 1200 символів зменшило hit@1 семантичного пошуку до 54,5%, тому обрано розмір 600 символів.

Семантичний пошук краще працює із синонімами, описками та складними запитами. BM25 забезпечує високу швидкість пошуку та добре знаходить точні артикули й коди помилок.

Експериментально визначено поріг косинусної схожості 0,8080. На тестовому наборі він дозволив відсіяти запит поза колекцією без втрати знайдених правильних документів.

Перевірено фільтрацію за товаром, статусом та аудиторією. Для клієнтського вебінтерфейсу доступ до внутрішніх документів обмежено на рівні бекенду.

За результатами експерименту встановлено, що семантичний пошук забезпечує вищу загальну результативність, а BM25 має перевагу у швидкості. У подальшому доцільно поєднати обидва методи для реалізації гібридного пошуку.

## Остаточна перевірка працездатності

| № | Перевірка | Фактичний результат | Статус |
|---|---|---|---|
| 1 | Пошук за артикулом OR-X2-BLK | Обидва методи знайшли потрібну інструкцію на першій позиції | Пройдено |
| 2 | Запит поза колекцією | Семантичний пошук не повернув результатів | Пройдено |
| 3 | Порожній запит у вебінтерфейсі | Браузер вимагає заповнити поле | Пройдено |
| 4 | Запуск без індексу | Застосунок відкривається та повідомляє про необхідність виконання ingest.py | Пройдено |
| 5 | Доступ до внутрішніх документів | HTTP 403 Forbidden — «Внутрішні документи недоступні клієнтам» | Пройдено |
| 6 | Невідомий режим пошуку | HTTP 400 Bad Request — «Невідомий режим» | Пройдено |
| 7 | Неіснуюче поле фільтрації | HTTP 400 Bad Request — «Невідоме поле фільтра» | Пройдено |
| 8 | Порожній запит через API | HTTP 400 Bad Request — «Введіть запит» | Пройдено |

Усі вісім перевірок пройдено успішно. Застосунок коректно обробляє некоректні запити, забезпечує обмеження доступу до внутрішніх документів та зберігає працездатність за відсутності індексу.

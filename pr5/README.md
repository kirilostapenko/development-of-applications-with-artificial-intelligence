# ПР5 — Семантичний пошук у колекції документів

FastAPI, локальна multilingual-e5-small (384 виміри), NumPy, BM25. 16 документів магазину «Сузірʼя». API-ключ не потрібен.

## Запуск (Windows, PowerShell)

```powershell
cd pr5
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
.\.venv\Scripts\python.exe ingest.py
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload
```

Відкрити http://127.0.0.1:8000. Перше завантаження моделі потребує інтернету. Індекс перебудовується після зміни документів, моделі або поділу. Без індексу сторінка показує інструкцію.

## Перевірка

У режимі «обидва способи» введіть OR-X2-BLK, refund policy, помилка E3. Перевірте top-k, оцінки, джерела, метадані та час. Для скидання до заводських налаштувань виберіть Альтаїр AX3. Для безкоштовної доставки порівняйте чинний та архівний статус. Вибір персоналу повертає 403: клієнт не має доступу до внутрішнього документа. Порожній запит та невідомий режим/поле фільтра повертають 400.

## Порівняння

12 запитів у compare/queries.json. Запустіть в іншому терміналі з pr5:

```powershell
.\.venv\Scripts\python.exe -m compare.run
```

Це необов'язковий спосіб виконати вимірювання замість ручного перенесення результатів. Він створює compare/results.md: два прогони (600 і 1200 символів), позиції, оцінки, час, hit@1/hit@3, додаткові перевірки фільтрів та кандидат порога. Індекс веб-застосунку не змінюється. Запити без відповіді не входять у знаменник hit@k. Внутрішній документ досліджується лише локально, не через клієнтський API. За результатами запишіть висновки у compare/findings.md і встановіть виміряний SIMILARITY_THRESHOLD у .env та .env.example, перезапустіть сервер.

## Рішення

Поділ за заголовками, довгі розділи — вікнами 600 символів із перекриттям 100, переважно по рядках. Табличні рядки за можливості залишаються цілими; перекриття може повторювати частину рядка. Назва документа та розділу додаються до тексту. E5 використовує query: і passage:, нормалізовані вектори; косинус — скалярний добуток. Індекс містить vectors.npy, chunks.json, назву моделі. BM25 використовує однакову токенізацію для запитів і документів, зберігає артикули, не застосовує стемінг. Фільтри до ранжування. За замовчуванням чинні клієнтські документи; архів можна вибрати явно. Оцінки BM25 і косинуса не порівнюються напряму. Модель кешується в процесі, час семантичного пошуку включає кодування запиту.

Індекс, .env і віртуальне середовище не комітяться. Фактичні вимірювання виконуються на вашому ПК.
